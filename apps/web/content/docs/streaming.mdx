---
title: Streaming
description: When searching for rare or uncached tracks, fetching lyrics across multiple platforms can take a few seconds. LyricsDB offers real-time streaming over Server-Sent Events (SSE) at `/api/lyrics/stream`.
---

## Endpoint Specification

- **URL**: `GET /api/lyrics/stream` (or alias `GET /api/tracks/stream`)
- **Headers**: `Accept: text/event-stream`
- **Parameters**:
  - `url`: Direct song/track URL from any streaming platform.
  - `platform` + `id`: Target platform identifier (`spotify`, `apple`, `deezer`, `netease`, `qq`, `isrc`) and ID.
  - `format`: Output format (default: `json`, supports `ttml`, `lrc`, `lrca2`, `yrc`, `qrc`, `eslrc`, `ass`, `lyl`, `lys`, `lqe`).
  - `forceRefresh`: Set to `true` to bypass cached database entries and force a live re-fetch.

---

## Event Lifecycle & Stages

The stream emits real-time events typed by `stage`:

| Stage | Description | Key Payload Data |
| :--- | :--- | :--- |
| `init` | Stream connection established | `platform`, `id`, `url`, `format` |
| `cache_hit` | Track found in PostgreSQL | `id`, `title`, `artists`, `lyricsType`, `lyricsProvider` |
| `cache_miss` | Track not in database; starting live resolution | `platform`, `id`, `url` |
| `resolving` | Platform adapter queries & metadata extraction | `step` (`extracting_metadata`, `parsed_metadata`, `searching_adapter`), metadata |
| `platform_matched` | Cross-platform track match verified | `platform`, `id`, `score` |
| `lyrics_searching` | Provider being queried for timed lyrics | `provider`, `lyricsType`, `status: "searching"` |
| `lyrics_found` | Synced lyrics found and validated | `provider`, `lyricsType`, `status: "found"` |
| `saving` | Ingesting track metadata and lyrics into database | `status: "saving"` |
| `done` | Final payload with sanitized track and formatted lyrics | `track`, `lyrics`, `format`, `contentType` |
| `error` | Resolution or network failure | `error` (error message) |

## Frontend Integration Example (JavaScript / TypeScript)

```ts
const eventSource = new EventSource(
  "/api/lyrics/stream?url=" + encodeURIComponent(songUrl) + "&format=ttml",
);

eventSource.onmessage = (event) => {
  const payload = JSON.parse(event.data);

  switch (payload.stage) {
    case "cache_miss":
      console.log("Cache miss:", payload.data);
      break;
    case "resolving":
      console.log("Resolving:", payload.data);
      break;
    case "platform_matched":
      console.log("Platform matched:", payload.data);
      break;
    case "lyrics_searching":
      console.log("Searching lyrics:", payload.data);
      break;
    case "lyrics_found":
      console.log("Lyrics found:", payload.data);
      break;
    case "saving":
      console.log("Saving:", payload.data);
      break;
    case "done":
      console.log("Completed track:", payload.data.track);
      console.log("Word-synced lyrics:", payload.data.lyrics);
      eventSource.close();
      break;
    case "error":
      console.error("Resolution error:", payload.data.error);
      eventSource.close();
      break;
  }
};
```
