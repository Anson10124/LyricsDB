## Base URLs

- **API Base URL**: `http://localhost:4000/api`
- **Swagger Interactive OpenAPI Explorer**: `http://localhost:4000/api/docs`

---

## Endpoint Directory

### Tracks

| Method & Path | Documentation | Description |
| :--- | :--- | :--- |
| `GET /api/tracks` | [Read Track](/docs/tracks/getTrack) | Look up or synchronize track metadata by URL or Platform ID. |
| `POST /api/tracks` | [Sync Track via Body](/docs/tracks/postTrack) | Synchronize track via JSON payload (`url` or `platform` + `id`). |
| `GET /api/tracks/search` | [Search Tracks](/docs/tracks/searchTracks) | Search cached database tracks by keyword query (`q`). |
| `GET /api/tracks/:id` | [Get Track by ID](/docs/tracks/getTrackById) | Retrieve track metadata by internal PostgreSQL database UUID. |

### Lyrics

| Method & Path | Documentation | Description |
| :--- | :--- | :--- |
| `GET /api/lyrics` | [Get Lyrics](/docs/lyrics/getLyrics) | Fetch synchronized lyrics by URL or Platform ID in any format. |
| `GET /api/tracks/:id/lyrics` | [Get Lyrics by ID](/docs/lyrics/getLyricsById) | Fetch lyrics for an existing database track ID. |
| `GET /api/lyrics/stream` | [Stream Lyrics](/docs/lyrics/streamLyrics) | Stream live resolution and extraction events over SSE. |
| `GET /api/tracks/stream` | [Stream Tracks](/docs/lyrics/streamLyrics) | SSE streaming alias for `/api/lyrics/stream`. |

## HTTP Status Codes

| Status Code | Reason | Resolution / Meaning |
| :--- | :--- | :--- |
| `200 OK` | Success | The track metadata or lyrics were retrieved successfully. |
| `400 Bad Request` | Invalid Input | Missing both `url` and `platform` + `id`, or invalid format/parameters. |
| `404 Not Found` | Not Found | The track was not found or no lyrics exist for the given song. |
| `500 Server Error` | Internal Error | Upstream provider outage or database failure. |
